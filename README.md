# Bootstrap 5 Flexbox Practical Assignment

## 📌 About the Project

This project demonstrates the use of Bootstrap 5 Flexbox utility classes to create flexible layouts and control the direction, wrapping, alignment, ordering, and growth of elements inside a flex container.

## 🎯 Objectives

- Understand Bootstrap 5 Flexbox utilities.
- Control the direction of flex items.
- Manage wrapping behavior inside containers.
- Align items horizontally and vertically.
- Rearrange items using the order property.
- Experiment with flex-grow to distribute available space.

## 📝 Practical Tasks

### 1. Flex Direction
Use Bootstrap classes to change the direction of five div elements:

- `flex-row`
- `flex-column`
- `flex-row-reverse`
- `flex-column-reverse`

### 2. Flex Wrapping
Control how items wrap inside the flex container:

- `flex-wrap`
- `flex-nowrap`
- `flex-wrap-reverse`

### 3. Horizontal Alignment
Use `justify-content` utilities to arrange items horizontally:

- `justify-content-start`
- `justify-content-center`
- `justify-content-end`
- `justify-content-between`
- `justify-content-around`

### 4. Vertical Alignment
Use `align-items` utilities to control the vertical alignment of items:

- `align-items-start`
- `align-items-center`
- `align-items-end`

### 5. Item Ordering
Use Bootstrap's `order-*` utility classes to rearrange flex items without changing the HTML structure.

### 6. Flex Grow
Experiment with `flex-grow-1` to allow items to expand and occupy available space inside the container.

## 🛠️ Technologies Used

- **HTML5** – Structure of the webpage.
- **CSS3** – Custom styling for flex items and containers.
- **Bootstrap 5** – Flexbox utility classes and responsive layouts.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure Bootstrap 5 CSS is included in your HTML file.
4. Open the HTML file in a web browser.
5. Use Live Server in VS Code to preview changes while experimenting with different Flexbox classes.

After completing this assignment, I gained practical knowledge of Bootstrap 5 Flexbox utilities and learned how to create flexible layouts, align elements, control wrapping, reorder items, and distribute available space.
